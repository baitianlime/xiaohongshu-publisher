# xiaohongshu-publisher

把主题或素材变成「复制即发」的小红书笔记草稿（标题、正文、标签、封面文案、配图建议；支持图文与视频）。

**只生成文案与人工发布指引，不登录小红书，不自动上传或发帖。**

## 安装

把本仓库目录复制到你的 Agent / Cursor skills 目录（目录名建议保持 `xiaohongshu-publisher`），确保包含：

```
xiaohongshu-publisher/
├── SKILL.md
├── references/
├── evals/          # 可选
├── README.md
├── LICENSE
└── CHANGELOG.md
```

不同宿主对 skill 的加载路径可能不同；以你所用产品的「自定义 skill / workflow」文档为准。

## 何时会用到

- 「帮我写一篇小红书笔记」
- 「把这段素材改写成小红书图文」
- 「写个小红书视频脚本」
- 「小红书种草文案」

不会用于：公众号 / 知乎 / 微博 / 抖音正文，或登录、上传等发布操作本身。

## 输出长什么样

每个备选版本包含：标题（≤20 字）、正文（≤1000 字）、话题标签 5–10 个、封面文案、配图建议、版本说明；文末附发布时间与互动建议。

### 示例（缩略）

**输入：** 新手养猫避坑

**版本 A · 避坑清单**

- 标题：`新手养猫必踩的5个坑，第3个最坑`
- 正文：共鸣开头 → 5 条避坑要点 → 收藏引导
- 标签：`#新手养猫` `#养猫避坑` `#养猫注意事项` …
- 封面：主「5 个坑」/ 副「第 3 个别踩」

（实际运行会产出完整 3 版，公式见 `references/title-formulas.md`。）
