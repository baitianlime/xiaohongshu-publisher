# 样例与去 AI 味

## 图文清单 · 好/坏对照（主题：新手养猫避坑）

### 坏例（勿学）

**标题：** `新手养猫必踩的5个坑，第3个最坑`  
问题：含绝对化「最」。

**正文（错误示范，含 Markdown 与编造）：**

```
**姐妹们听我的！** 我养猫一周就瘦了4斤（编造数据）……

赋能你的养宠生活，沉浸式避坑指南来啦！打造完美养猫人设～

# 坑1
百分百别买自动喂食器……
```

问题清单：

- 绝对化：最、百分百
- 编造第一人称结果数据（瘦了 4 斤）
- 正文用了 `**` / `#`，发布框会原样显示
- AI 套话：赋能、沉浸式、打造、人设

### 好例（可学结构）

**标题：** `新手养猫必踩的5个坑，第3个超坑`

**正文（纯文本，经历用占位）：**

```
养猫第一周我差点劝退，后来才知道是自己踩坑了。

把这 5 条收好，少走弯路：

1. 一上来就买全套「网红用品」
很多其实用不上。建议先【待补充：你实际先买的 3 样】，住稳再添。

2. 粮和水的位置太远
猫容易懒得跑。我是把【待补充：你的摆放方式】，情况好很多。

3. 随便用消毒液（这条超坑）
气味大、刺激呼吸道。我改成【待补充：你在用的清洁方式】。

4. 一天吸八百次猫
初来乍到压力大。前几天先【待补充：你的相处节奏】。

5. 有点不对劲就自己瞎查
精神差、不吃东西，及时问医生。以下仅供参考，不构成医疗建议。

你现在卡在哪一条？评论区聊聊，我一条条回。
```

**标签示例：** `#新手养猫` `#养猫避坑` `#养猫注意事项` `#养猫日记` `#宠物护理` `#吸猫日常` `#养猫心得`

**封面：** 主「5 个坑」/ 副「第 3 条超坑」

**版本说明：** 避坑清单型；适合零基础铲屎官收藏。

要点：清单条目可自拟；价格 / 亲测结果 / 「我用了多久」用占位；无 Markdown；语气像朋友聊天。

## 去 AI 味清单（写作自检）

- [ ] 有没有连续排比、空洞形容词（赋能 / 打造 / 沉浸式 / 极致 / 氛围感堆砌）？
- [ ] 句子是否过长、像报告？改成短句、口语、可穿插一点语气词
- [ ] 是否用具体场景（时间、地点、物件）代替空抒情？
- [ ] 第一人称数据是否都来自用户或已占位？
- [ ] 正文是否纯文本（无 `**`、`##`、列表用「1. 2.」或换行即可）？
- [ ] 若用户贴了 2–3 篇旧笔记：句长、称呼、口头禅是否对齐？

宁可朴素真实，不要「很完整但很假」。
