# 关键词挖掘与 SEO 方法

字数与标签个数上限见 `platform-rules.md`（唯一来源），本文不重复硬编码。

## 挖掘关键词

1. 从主题拆出核心词（如「养猫」→ 新手养猫 / 养猫注意事项）
2. 补长尾词：人群 + 场景 + 问题（如「学生党养猫省钱」「夏天养猫掉毛」）
3. 联想相关词：品类词、替代说法（如 平价 / 平替 / 避雷 / 测评 / 教程）
4. 有搜索能力时，可参考同主题热帖的**关键词与结构**；**只借鉴关键词和结构，不复述原文**（防洗稿）
5. 无检索能力时，不要伪造「热搜榜 / 今日热帖」数据；用主题合理拆词即可

## 布局规则

- **标题：** 核心关键词必现，尽量放在前 8 个字
- **正文：** 前 100 字自然出现 1–2 次；全文不堆砌。  
  ~~旧说「关键词密度 2–5%」~~：**已弃用**（无可靠出处，且与「前 100 字 1–2 次、不堆砌」冲突；按字数占比会过度重复）
- **标签：** `#核心词` `#长尾词` `#人群词` `#场景词`，数量见 platform-rules；**按相关度从大词到长尾排列**（本技能无搜索量 API 时，不要写「按搜索量排序」）

## 输出检查

- 标题、正文、标签的关键词互相呼应，不各说各话
- 不塞无关热词蹭流量
- 用户指定了目标关键词时优先使用用户的关键词
- 参考热帖时：换结构、换表述，保留信息增量，避免洗稿观感
