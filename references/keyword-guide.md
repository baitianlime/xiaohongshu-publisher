# 关键词挖掘与 SEO 方法

## 挖掘关键词

1. 从主题拆出核心词（如「养猫」→ 新手养猫 / 养猫注意事项）
2. 补长尾词：人群 + 场景 + 问题（如「学生党养猫省钱」「夏天养猫掉毛」）
3. 联想相关词：品类词、替代说法（如 平价 / 平替 / 避雷 / 测评 / 教程）
4. 有搜索能力时，参考同主题热帖标题用语；没有时不要伪造「热搜榜」数据

## 布局规则

- 标题：核心关键词必现，尽量放在前 8 个字
- 正文：前 100 字自然出现 1–2 次，全文不堆砌（关键词密度约 2–5%）
- 标签：#核心词 #长尾词 #人群词 #场景词，5–10 个，按搜索量从大到小排列

## 输出检查

- 标题、正文、标签的关键词互相呼应，不各说各话
- 不塞无关热词蹭流量
- 用户指定了目标关键词时优先使用用户的关键词
