# 标题钩子公式库

每条公式附 2 个示例，示例均 ≤20 字。同篇多版本应使用不同公式切入。

## 1. 数字 + 结果

公式：数字 + 动作/时间 + 结果

- 「7天戒掉奶茶，我瘦了4斤」
- 「3件百元内好物，用回本了」

## 2. 悬念反问

公式：疑问 + 反差细节

- 「为什么越勤快的人越容易长痘？」
- 「家里这5样东西，早该扔了？」

## 3. 痛点直击

公式：人群 + 痛点 + 转折

- 「新手养猫必踩的5个坑，第3个最坑」
- 「油皮夏天化妆总脱妆？试试这个顺序」

## 4. 反差对比

公式：A 却 B / 从 X 到 Y

- 「月薪5千，靠这个副业存下3万」
- 「从烂脸到素颜出门，我只改了1件事」

## 5. 避坑清单

公式：避雷 + 数量 + 目标

- 「双11避雷清单：这8类东西别买」
- 「租房前先看这6条，少亏一个月工资」

## 6. 情感共鸣

公式：场景 + 情绪 + 共鸣

- 「28岁裸辞后，我才学会休息」
- 「一个人搬家那天，我哭了」

## 使用提示

- 每条标题放 1 个核心关键词
- 数字用阿拉伯数字更吸睛
- 3 个版本分别用不同公式，覆盖不同读者偏好
