# 标题钩子公式库

每条公式附示例，示例均 ≤20 字。同篇多版本应使用不同公式切入。

**硬规则：** 示范标题**不得**使用「最」「第一」「百分百」「永久」等绝对化夸大。  
**反编造：** 带具体结果数字的示例仅作**结构示例**；真实数字须用户提供，否则输出时改为 `【待补充】` 或换成无具体结果的钩子。

## 1. 数字 + 结果

公式：数字 + 动作/时间 + 结果

- 「7天戒掉奶茶，体态有变化」（结构示例；真实变化须用户提供）
- 「3件百元内好物，用着真香」

## 2. 悬念反问

公式：疑问 + 反差细节

- 「为什么越勤快的人越容易长痘？」
- 「家里这5样东西，早该扔了？」

## 3. 痛点直击

公式：人群 + 痛点 + 转折

- 「新手养猫必踩的5个坑，第3个超坑」
- 「油皮夏天化妆总脱妆？试试这个顺序」

## 4. 反差对比

公式：A 却 B / 从 X 到 Y

- 「月薪普通，副业存钱有方法」（结构示例；金额须用户提供）
- 「从烂脸到敢素颜，我只改了1件事」（结构示例；经历须用户提供或占位）

## 5. 避坑清单

公式：避雷 + 数量 + 目标

- 「双11避雷清单：这8类东西别买」
- 「租房前先看这6条，少花冤枉钱」

## 6. 情感共鸣

公式：场景 + 情绪 + 共鸣

- 「28岁裸辞后，我才学会休息」
- 「一个人搬家那天，情绪崩了」

## 使用提示

- 每条标题放 1 个核心关键词
- 数字用阿拉伯数字更吸睛；清单数量可自拟，结果数据不可编
- 3 个版本分别用不同公式，覆盖不同读者偏好
- 自检标题 ≤20 字，且不含绝对化夸大词
